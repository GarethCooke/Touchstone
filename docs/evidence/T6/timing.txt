2. The argument clone (wasm/timing.mjs, section 2)
--------------------------------------------------

  The four timings the audit took, rerun here. A 200,704-value Float64Array of values
  100 + (i mod 97); its 256-value subarray at offset 1,024; a Float64Array copy of that
  subarray; the whole array; the same values as a plain array. structuredClone of each, in
  loops of 1,000, 100 and 10, the line giving the median loop and the cost of one clone.

  structuredClone, a 256-value subarray of 200,704              731.184 ms  (709.889 to 756.015)    731.184 µs each
  structuredClone, a 256-value Float64Array of its own            2.587 ms  (1.935 to 4.308)      2.587 µs each
  structuredClone, the whole 200,704-value Float64Array          73.354 ms  (69.044 to 79.678)    733.539 µs each
  structuredClone, the same values as a plain array              45.862 ms  (42.238 to 53.252)   4586.170 µs each

  Beside the audit's (Node 22.23.5, a cloud container, one run): 329 µs, 5.5 µs, 369 µs and
  3.4 ms. The shape is the same here: a subarray costs what its whole buffer costs, and a
  plain array costs about six times a typed one. errors.post.js therefore copies a partial
  view into a buffer of its own before the clone (ARCHITECTURE.md §8), and the smoke test
  holds each 256-value slice to a 2,048-byte buffer at the clone.

4. What the slice copy costs every call
---------------------------------------

  errors.post.js now looks at each argument before the clone. priceAndGreeks(...).delta,
  200,000 calls, on v1.0.0's artifact and this branch's, three runs of the script above in
  two orders:

    first run, v1.0.0 first          v1.0.0 11.18 µs   branch 12.35 µs  (the copy by map)
    second run, v1.0.0 first         v1.0.0 12.50 µs   branch 12.76 µs  (the copy in place)
    third run, branch first          v1.0.0 11.02 µs   branch 12.73 µs
    final run (section 3)            v1.0.0 11.28 µs   branch 10.93 µs

  The first form built a new arguments array on every call; it was replaced by a loop over
  the arguments in place. After that, the difference between the two artifacts is inside
  the spread of either from run to run (11.0 to 12.8 µs), so nothing is claimed for it
  either way.

5. The TypeScript harness (section 3), as run
---------------------------------------------

    // The brief's two figures, rerun: the site's TypeScript `delta` a call against
    // the module's `priceAndGreeks(...).delta` a call, and D5's live sample on the
    // TypeScript numerics against 200,000 calls through the module. Read-only use
    // of touchstone-learn at 8d7293c; bundled with that repository's esbuild.
    import { cpus } from 'node:os'
    import { pathToFileURL } from 'node:url'
    import { delta as bsDelta } from 'C:/Development/Projects/Touchstone-Learn/src/demos/blackScholes'
    import { hedgeSample, samplePaths } from 'C:/Development/Projects/Touchstone-Learn/src/demos/experiments/hedging'
    import { tsBackend } from 'C:/Development/Projects/Touchstone-Learn/src/demos/tsBackend'
    import experiment from 'C:/Development/Projects/Touchstone/experiments/2_7_delta_hedging.json'
    
    const runs = 9
    const time = (body: () => void) => {
      body()
      const taken: number[] = []
      for (let r = 0; r < runs; r++) {
        const start = performance.now()
        body()
        taken.push(performance.now() - start)
      }
      taken.sort((a, b) => a - b)
      return { median: taken[runs >> 1], least: taken[0], most: taken[runs - 1] }
    }
    const report = (label: string, t: { median: number; least: number; most: number }, per?: number) =>
      console.log(`${label.padEnd(62)} ${t.median.toFixed(3).padStart(10)} ms  (${t.least.toFixed(3)} to ${t.most.toFixed(3)})` +
        (per === undefined ? '' : `   ${((t.median * 1000) / per).toFixed(3).padStart(8)} µs each`))
    
    const p = experiment.params
    const calls = 200_000
    const spots = Float64Array.from({ length: calls }, (_, i) => 80 + (i % 401) * 0.1)
    const times = Float64Array.from({ length: calls }, (_, i) => 1 - (i % 256) / 256)
    
    console.log(`Node ${process.version}; ${cpus()[0].model.trim()}`)
    console.log(`median of ${runs} runs after one untimed run`)
    let sink = 0
    report(`TypeScript delta, ${calls.toLocaleString('en')} calls`, time(() => {
      for (let i = 0; i < calls; i++) {
        sink += bsDelta({ strike: 100, expiryYears: times[i], type: 'call' }, { spot: spots[i], vol: 0.2, rate: 0.05, dividendYield: 0 })
      }
    }), calls)
    
    const histograms = { hedged: { lo: -10, hi: 10, bins: 40 }, unhedged: { lo: -20, hi: 40, bins: 60 } }
    const rebalances = 256
    const paths = samplePaths(rebalances)
    const spec = { seed: 1, paths, rebalances, spot: p.S0, strike: p.K, expiryYears: p.T, drift: 0, impliedVol: p.sigma_implied ?? 0.2,
      realisedVol: p.sigma_implied ?? 0.2, rate: p.r, type: 'call' as const }
    report(`D5 hedgeSample on the TypeScript numerics, N = ${rebalances}, ${paths} paths`, time(() => {
      sink += hedgeSample(tsBackend, spec, histograms).mean
    }))
    
    for (const [label, path] of [['v1.0.0', process.argv[2]], ['this branch', process.argv[3]]]) {
      if (!path) continue
      const { default: create } = await import(pathToFileURL(path).href)
      const t = await create()
      report(`module ${label} (${t.version}): priceAndGreeks(...).delta, ${calls.toLocaleString('en')} calls`, time(() => {
        for (let i = 0; i < calls; i++) {
          sink += t.priceAndGreeks({ strike: 100, expiryYears: times[i], type: 'call' }, { spot: spots[i], vol: 0.2, rate: 0.05, dividendYield: 0 }).delta
        }
      }), calls)
    }
    if (Number.isNaN(sink)) console.log('unreachable')
