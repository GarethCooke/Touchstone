Your predictions, before any code ran

Why — no limit needed

3It is 2.3's identity, rearranged

You already wrote this in 2.3 for g(x) = x²: over one step, (W + ΔW)² − W² = 2W·ΔW + (ΔW)². Solve it for the thing 2.4 wants, W·ΔW = ½[(W + ΔW)² − W²] − ½(ΔW)², and add up the n steps. The first bracket telescopes — every W(tᵢ)² appears once with a plus and once with a minus except the ends — leaving ½W_T² − ½W₀² = ½W_T² because W₀ = 0. So on every grid, for every path:

P1 · left   Σ W(tᵢ)·ΔWᵢ = ½W_T² − ½Σ(ΔW)²
exact algebra, checked to 2 × 10⁻¹⁵ on 400 paths × 5 grids (identities_max_abs_residual.left)
P2 · mid   Σ W(mᵢ)·ΔWᵢ = ½W_T² + ½(Σδ₁² − Σδ₂²)
split each step into two half-steps with increments δ₁ (first half) and δ₂ (second half), ΔW = δ₁ + δ₂. Then W(mᵢ) = W(tᵢ) + δ₁, and the same algebra leaves the difference of the two half-step quadratic variations
P3 · right   Σ W(tᵢ₊₁)·ΔWᵢ = ½W_T² + ½Σ(ΔW)²
ΔWᵢ = W(tᵢ₊₁) − W(tᵢ) by definition, so W(tᵢ₊₁) = W(tᵢ) + ΔWᵢ. Then W(tᵢ₊₁)·ΔWᵢ = (W(tᵢ) + ΔWᵢ)·ΔWᵢ = W(tᵢ)·ΔWᵢ + (ΔWᵢ)²: each right term is the left term plus the square of the move. Sum: right = left + Σ(ΔW)², and with left = ½W_T² − ½Σ(ΔW)² that is ½W_T² + ½Σ(ΔW)²
(left + right) / 2 = ½W_T²
trapezoid: average the left and right lines and the ±½Σ(ΔW)² cancel. The chain-rule answer, exactly, on every grid — path 1 at n = 100: (0.2595 + 1.3334)/2 = 0.7965 = ½·1.2621². The midpoint sum tends to the same number but is exact only in the limit
Aside — the telescoping, written out

Write Wᵢ for W(tᵢ). Then (W + ΔW)² − W² on step i is just Wᵢ₊₁² − Wᵢ², and the sum of consecutive differences collapses to last minus first — the sections of a telescope sliding into each other. For n = 3:

step 0:  (W₀ + ΔW₀)² − W₀²  =  W₁² − W₀²
step 1:  (W₁ + ΔW₁)² − W₁²  =  W₂² − W₁²
step 2:  (W₂ + ΔW₂)² − W₂²  =  W₃² − W₂²
                              ─────────────
sum:                          W₃² − W₀²  =  W_T²     (W₀ = 0)

W₁² enters step 0 with a plus and step 1 with a minus; W₂² likewise. Only the two ends survive; no randomness is left in that step and no limit is taken. The ½[…] itself is 2.3's one-step expansion solved for the term 2.4 wants: (Wᵢ + ΔWᵢ)² − Wᵢ² = 2WᵢΔWᵢ + (ΔWᵢ)², so Wᵢ·ΔWᵢ = ½[(Wᵢ + ΔWᵢ)² − Wᵢ²] − ½(ΔWᵢ)². Sum over the grid: the first piece telescopes to ½W_T², the second is ½Σ(ΔW)². Made-up three-step check: W = 0, 0.3, −0.1, 0.5 gives ΔW = 0.3, −0.4, 0.6; the left sum is 0·0.3 + 0.3·(−0.4) + (−0.1)·0.6 = −0.18, and ½·0.5² − ½·(0.09 + 0.16 + 0.36) = 0.125 − 0.305 = −0.18. Same number at n = 3; the limit enters only when Σ(ΔW)² is replaced by T.

Aside — the midpoint identity, derived

On one step write Wᵢ = W(tᵢ), Wₘ = W(mᵢ), Wᵢ₊₁ = W(tᵢ₊₁); the half-step changes are δ₁ = Wₘ − Wᵢ and δ₂ = Wᵢ₊₁ − Wₘ, so ΔWᵢ = δ₁ + δ₂ and Wₘ = Wᵢ + δ₁.

W(mᵢ)·ΔWᵢ = (Wᵢ + δ₁)(δ₁ + δ₂) = Wᵢ·ΔWᵢ + δ₁² + δ₁δ₂
sum:   mid = left + Σδ₁² + Σδ₁δ₂                                 (A)

left = ½W_T² − ½Σ(ΔW)²  and  Σ(ΔW)² = Σ(δ₁+δ₂)² = Σδ₁² + 2Σδ₁δ₂ + Σδ₂²
mid  = ½W_T² − ½Σδ₁² − Σδ₁δ₂ − ½Σδ₂² + Σδ₁² + Σδ₁δ₂
     = ½W_T² + ½(Σδ₁² − Σδ₂²)                                    (B)

(A) and (B) are the same identity; the card shows (B) because the limit is then plain: Σδ₁² is a quadratic variation over n half-steps of length dt/2, so it → n·dt/2 = ½T, and Σδ₂² → ½T likewise; the difference dies and mid → ½W_T². The JSON checks both forms to 10⁻¹⁵ (identities_max_abs_residual.mid, .mid_halves). The picture: a midpoint term is Wₘ·δ₁ + Wₘ·δ₂. The second piece is a left-endpoint term on the half-step grid; the first is a right-endpoint term (position at the end of the first half-step, times its move), and a right-endpoint term is the left one plus the square of the move. So the midpoint sum is the left sum on 2n half-steps, peeking on every odd one — it gains Σδ₁² ≈ ½T, which is E[mid] = ½T: half an insider. Two-step check, W at t = 0, ¼, ½, ¾, 1 being 0, 0.2, 0.3, −0.1, 0.5: step 0 has δ₁ = 0.2, δ₂ = 0.1, ΔW = 0.3; step 1 has δ₁ = −0.4, δ₂ = 0.6, ΔW = 0.2. Mid sum = 0.2·0.3 + (−0.1)·0.2 = 0.04; (B) gives ½·0.5² + ½(0.20 − 0.37) = 0.04; left = 0·0.3 + 0.3·0.2 = 0.06 and (A) gives 0.06 + 0.20 + (0.02 − 0.24) = 0.04.

Now let n → ∞ and use the one fact 2.3 established: Σ(ΔW)² → T, path by path. The left sum (P1) goes to ½W_T² − ½T. For the midpoint (P2), each set of half-steps carries half the quadratic variation — Σδ₁² → ½T and Σδ₂² → ½T (measured: 0.5000 and 0.5000 at n = 10⁶) — so their difference dies and the midpoint sum goes to ½W_T², which is what the chain rule would have said. The right sum (P3) goes to ½W_T² + ½T. Three limits, and the two gaps between them are ½T and T: 2.3's number, halved and whole.

For a smooth curve the same three identities hold with x in place of W, and Σ(Δx)² → 0, so all three limits coincide at ½x_T². That is the whole difference between the two calculi in one line: the endpoint matters exactly when Σ(Δ·)² does not vanish. §6 has the numbers.

Aside — three cheap checks on any candidate answer

Units. W has units of √time (Var(W_t) = t, so sd is √t); ΔW likewise. W·ΔW is √time × √time = time, so the sum is time, and so is ½W_T² − ½T. T·W_T is time × √time = time^(3/2): not in the running before a single number is looked at.

The factor. d(x²) = 2x dx, so x dx = ½ d(x²), so Σ x·Δx → ½x_T² for anything smooth. A candidate W_T² has the right units but is twice the chain-rule value — the ½ has been dropped. Units cannot catch this one, since W_T² and ½W_T² have the same units.

Expectation. E[Σ W(tᵢ)·ΔWᵢ] = 0 (§4). E[W_T²] = T and E[½W_T²] = ½T, so neither can be the answer; the only way to bring the mean to zero is to subtract ½T, and E[½W_T² − ½T] = ½T − ½T = 0. This check kills the chain-rule answer as well as W_T², and forces the correction term.

Aside — the spread of the midpoint error, derived

A half-step has length dt/2, so a half-step increment is δ ~ N(0, dt/2) and δ² = (dt/2)·Z² with Z ~ N(0, 1). From 2.3, Var(Z²) = 2, so Var(δ²) = 2·(dt/2)² = dt²/2. Σδ₁² is n independent such terms: variance n·dt²/2 = T·dt/2 = T²/(2n). Σδ₂² has the same variance and is independent of Σδ₁² (different increments). The error is ½(Σδ₁² − Σδ₂²): variance ¼·(T²/(2n) + T²/(2n)) = T²/(4n); sd = T/(2√n). Units: T²/n is time², its root is time, matching the sum. Compare the left error −½(Σ(ΔW)² − T): variance ¼·Var(Σ(ΔW)²) = ¼·2T²/n = T²/(2n); sd T/√(2n) = 0.707·T/√n against the midpoint's 0.5·T/√n. The midpoint sum converges a little faster — and finance still cannot use it (§5).

Expectations

4Zero mean, martingale, isometry — and what peeking earns

Now 20,000 paths at n = 10⁴, and ask what the sums do on average. A left-endpoint term is W(tᵢ)·ΔWᵢ, where ΔWᵢ is the change over the step that starts at tᵢ. Independent increments (2.2) say ΔWᵢ knows nothing about the path before tᵢ, so it is independent of W(tᵢ), and E[W(tᵢ)·ΔWᵢ] = E[W(tᵢ)]·E[ΔWᵢ] = anything × 0 = 0. Every term has mean zero, so the sum does. A right-endpoint term is W(tᵢ₊₁)·ΔWᵢ = W(tᵢ)·ΔWᵢ + (ΔWᵢ)²: the same zero-mean piece plus a (ΔW)², mean dt. Sum n of them and the mean is n·dt = T. Running total: a martingale in t

Let I(t) be the left sum over the steps before t — the integral "so far". Its mean is 0 at every t, not only at T. Its mean-square grows like ½t². And the second half of the sum has no memory of the first: knowing I(½T) tells you nothing about I(T) − I(½T). That is the martingale property from 2.2 (E[X_t | F_s] = X_s: the best forecast is the present value), now for the integral rather than the path. The right sum R(t), by contrast, drifts upward at rate 1: E[R(t)] = t.

Aside — the Itô isometry, derived from the grid

Square the left sum and expand: (Σᵢ Wᵢ·ΔWᵢ)² = Σᵢ Σⱼ Wᵢ·ΔWᵢ·Wⱼ·ΔWⱼ, with Wᵢ short for W(tᵢ). Take expectations term by term. Off the diagonal, say i < j: ΔWⱼ is the change over a step that starts after everything else in the term is known (Wᵢ, ΔWᵢ, Wⱼ all sit at or before tⱼ), so it is independent of them and has mean 0 — the term vanishes. On the diagonal, i = j: E[Wᵢ²·(ΔWᵢ)²] = E[Wᵢ²]·E[(ΔWᵢ)²] = tᵢ·dt, again by independence. So E[(left sum)²] = Σ tᵢ·dt, which is the ordinary integral ∫₀ᵀ t dt = ½T² in the limit and dt²·(0 + 1 + … + (n−1)) = ½T²·(1 − 1/n) exactly on the grid. The general statement, E[(∫H dW)²] = ∫E[H²] dt, is the Itô isometry: the mean-square of a stochastic integral is an ordinary integral of the mean-square integrand. Here it says sd(∫₀ᵀ W dW) = T/√2 = 0.707; measured 0.696. Cross-check by the identity: E[(½W_T² − ½T)²] = ¼(E[W_T⁴] − 2T·E[W_T²] + T²) = ¼(3T² − 2T² + T²) = ½T². Same number, two routes.

The finance reason

5The integrand is the position you hold over the next step

Your P5 had the idea; here is the sharp form. Trade a stock S on the grid. At time tᵢ you decide how many shares to hold, call it h(tᵢ), and you hold them until tᵢ₊₁. Over that step the price moves by ΔSᵢ = S(tᵢ₊₁) − S(tᵢ) and your P&L is h(tᵢ)·ΔSᵢ: what you held, times how much it moved. Total P&L to T is Σ h(tᵢ)·ΔSᵢ — a left-endpoint sum, not by convention but by construction. The position is fixed at the start of the step because that is when you trade; the price change arrives afterwards.

The right-endpoint sum Σ h(tᵢ₊₁)·ΔSᵢ is the P&L of someone who sees the step's price move and then chooses the position that was held during it. The midpoint sum sees half of it. With h = S = W, §4 measured what that is worth: E[right] = T and E[mid] = ½T, against E[left] = 0 — a guaranteed profit from information nobody has. The words for the rule are that the integrand must be adapted, or non-anticipating: h(t) may depend only on what is known at t — F_t, the filtration from 2.2. The Itô integral is the left-endpoint limit because it is the only one of the three that a trader can realise, and its zero mean is the statement that no adapted strategy has an edge on a driftless price.

Aside — Stratonovich, since the index asks

The midpoint limit ½W_T² is the Stratonovich integral, written ∫W ∘ dW with a small circle. It obeys the ordinary chain rule — which is exactly why physicists like it for noise that is the limit of something smooth — and it is related to Itô's by ∫W ∘ dW = ∫W dW + ½T, the ½T being half the quadratic variation of the integrand against W (in general ½∫dH·dW). Two things disqualify it here: its integrand looks half a step ahead, so no trader can hold it, and §4 shows the consequence — E = ½T, not a martingale. On this course "∫ … dW" always means Itô. The circle is the only thing the page needs to be able to recognise.

The contrast

6For a smooth curve the endpoint does not matter

Take x(t) = t² on the same five grids and form the same three sums Σ x·Δx. The identities of §3 hold letter for letter; the difference is that Σ(Δx)² → 0 — each Δx ≈ x′(t)·dt = 2t·dt is dt-sized, so its square is dt²-sized and n of them make (4/3)·dt → 0 (the 4/3 is ∫₀¹(2t)² dt). All three sums land on ½x_T² = ½, the chain rule d(x²) = 2x dx:

The exact case

7The coin walk has it exactly

For the ±√dt coin walk of 2.1, Σ(ΔW)² = n·dt = T on every grid with no spread at all (2.3, C5). Put that into the §3 identity and the left sum is ½W_T² − ½T exactly, at n = 100 as much as at n = 10⁶, and the right sum ½W_T² + ½T exactly; the JSON's worst deviation across five grids and five paths is 5 × 10⁻¹⁴ (results.coin[*]). At n = 100 one coin path ends at W_T = −1.0 and its left sum is 0.000 (−1.2 × 10⁻¹⁶): up-and-down by one, and the integral is zero, the same story as path 5 in §2 without the Gaussian noise. Itô's −½T is not an artefact of Gaussian steps or of the limit; it is the price of √dt-sized steps, and the coin pays it in full at every n.

8Draft check questions

Per I5: each wrong option names the misconception it encodes and the feedback says why it is wrong. Q1's "T·W_T" and Q2's "all three agree" are your own pre-run predictions (P1, P2/P3).

Q1

A Brownian path on [0, 1] is chopped into n equal steps and you compute Σ W(tᵢ)·ΔWᵢ with W read at the start of each step. As n → ∞ it tends to:

  • ½W_T² − ½T — the x² identity gives ½W_T² − ½Σ(ΔW)² on every grid, and Σ(ΔW)² → T.
  • ½W_T² — the chain rule assumed. d(W²) = 2W dW needs Σ(ΔW)² → 0. It is T. The sum is short of ½W_T² by exactly half of it.
  • T·W_T — units not carried. W and ΔW each have units of √time, so the sum has units of time; T·W_T has time^(3/2). Whatever the limit is, it is not this.
  • W_T² — the ½ of the chain rule dropped and the −½T never seen. x dx = ½ d(x²), so even for a smooth x, Σ x·Δx → ½x_T², not x_T². And E[W_T²] = T while the sum has mean 0 (Q3).
Q2

Same path, same grids, but now W is read at the midpoint of each step, or at the end. As n → ∞, compared with the left-endpoint sum:

  • Midpoint lands ½T higher, endpoint T higher — three different limits — right − left = Σ(ΔW)² → T exactly; mid − left → ½T.
  • All three agree in the limit, as Riemann sums do — smooth intuition. Riemann sums agree because the gap between them is Σ(Δx)², which vanishes for a smooth curve. For W that gap is the quadratic variation, T, on every grid.
  • They differ at finite n but the differences vanish as n → ∞ — the gap mistaken for a discretisation error. The gap right − left is not an error that refines away: it is Σ(ΔW)², and 2.3 measured it at 1.00 on every grid from 10² to 10⁶.
  • They differ by a random amount that depends on the path — quadratic variation as a path property. The gap is Σ(ΔW)², which is T for every path (spread √(2/n) → 0). Path 1 and path 5 have different limits but the same three gaps.
Q3

E[Σ W(tᵢ)·ΔWᵢ] for the left-endpoint sum is:

  • 0 — ΔWᵢ is the change over a step that starts at tᵢ, independent of W(tᵢ) and mean zero, so every term has mean zero. Consistent with E[½W_T² − ½T] = ½T − ½T = 0.
  • T — the right-endpoint mean. W(tᵢ₊₁)·ΔWᵢ = W(tᵢ)·ΔWᵢ + (ΔWᵢ)², and the (ΔW)² terms sum to T. Reading W at the end of the step is what earns it.
  • ½T — the midpoint mean, or ½E[W_T²] with the −½T forgotten. The midpoint integrand has already seen half the step; the left one has seen none of it.
  • It depends on the path — expectation confused with a path value. The sum's value depends on the path (½W_T² − ½T does); its expectation is an average over paths and is one number. It is 0: measured −0.004 ± 0.005 over 20,000 paths.
Q4

In finance the integrand of ∫h dS is always read at the left endpoint of each step. Why?

  • h(tᵢ) is the position held over [tᵢ, tᵢ₊₁]; it must be fixed before the step's price change is known — that is what trading is. The zero mean follows from it, not the other way round.
  • It is the convention that makes the integral a martingale, adopted for mathematical convenience — consequence taken for cause. The martingale property is what you get once the integrand cannot see the step. Non-anticipation is the requirement; zero mean is its shadow.
  • Any endpoint works — they agree in the limit — smooth intuition again. They differ by ½T and T (Q2), and the difference has a name: E[right] = T is the profit of a trader who chooses the position after seeing the move.
  • The left endpoint gives the smallest error at finite n — accuracy mistaken for legitimacy. The midpoint sum's error spread is T/(2√n), smaller than the left's T/√(2n). It is still a sum nobody can trade.
Q5

E[(∫₀ᵀ W dW)²] — the mean-square of the Itô integral — equals:

  • ½T² — the Itô isometry: E[(∫H dW)²] = ∫₀ᵀ E[H²] dt, and ∫₀ᵀ t dt = ½T². Cross-check: E[(½W_T² − ½T)²] = ¼(3T² − 2T² + T²) = ½T².
  • T — the quadratic variation of W substituted for the variance of the integral. Σ(ΔW)² = T is about W; the question is about ∫W dW, whose spread grows with how big W itself gets — hence the extra factor of t under the integral.
  • 0, because E[∫W dW] = 0 — mean and mean-square confused. A zero-mean quantity can be as spread out as you like. sd(∫₀ᵀ W dW) = T/√2 = 0.707 at T = 1; measured 0.696.
  • ¾T², from E[(½W_T²)²] = ¼E[W_T⁴] = ¾T² — the chain-rule value squared. The integral is ½W_T² − ½T, not ½W_T²; the −½T is worth exactly ¼T² in the mean-square.
