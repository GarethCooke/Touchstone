T0 — test log
=============

Two things are proved here: that the generator reruns reproducibly (the milestone's
first exit criterion), and that the file it produces is worth trusting.

-------------------------------------------------------------------------------
1. Reproducibility — same QuantLib version, same bytes
-------------------------------------------------------------------------------

The generator is run twice more into a scratch directory and both are compared with
the committed file. The evaluation date is fixed in source and no timestamp is
written into the output, so byte-identity is the right test rather than a value
comparison with a tolerance.

$ uv run golden/generate_bs_vanilla.py --out /tmp/repro/run1.json
wrote /tmp/repro/run1.json — QuantLib 1.43, 7200 cases + 34 edge cases
$ uv run golden/generate_bs_vanilla.py --out /tmp/repro/run2.json
wrote /tmp/repro/run2.json — QuantLib 1.43, 7200 cases + 34 edge cases

$ sha256sum golden/bs_vanilla.json /tmp/repro/run1.json /tmp/repro/run2.json

2. Independent cross-check — golden/verify_bs_vanilla.py
-------------------------------------------------------------------------------

Re-derives price and all six Greeks for every row from the closed form in SCHEMA.md,
using math.erfc — the route std::erfc gives the C++ at T1 — then checks put-call
parity, the sign and unit conventions, and the document's own structure.
