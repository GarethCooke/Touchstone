4. The three pairs in pde.hpp: the overload probe
-------------------------------------------------

  require_valid, crank_nicolson and crank_nicolson_surface are each declared for
  EuropeanVanilla and AmericanVanilla and forward to one template in src/pde.cpp. The probe
  mirrors the declarations that matter — bump_greeks.hpp's three-argument require_valid
  taking BumpSizes, and pde.hpp's pair — and calls require_valid(EuropeanVanilla{},
  BlackScholesMarket{}, {}) with the pair as it is and with the pair folded into one
  template:

    // What `require_valid(option, market, {})` resolves to when bump_greeks.hpp's
    // overload is visible, with pde.hpp's pair as it is (FOLDED undefined) and as
    // one template (FOLDED defined). Mirrors the declarations only.
    #include <cstdio>
    enum class Exercise { European, American };
    template <Exercise E> struct Vanilla { double strike{}, expiry_years{}; int type{}; };
    using EuropeanVanilla = Vanilla<Exercise::European>;
    using AmericanVanilla = Vanilla<Exercise::American>;
    struct BlackScholesMarket { double spot{}, vol{}, rate{}, dividend_yield{}; };
    struct PdeSettings { unsigned long space_intervals{1024}; };
    struct BumpSizes { double spot_relative{1e-6}; };

    // bump_greeks.hpp
    void require_valid(const EuropeanVanilla&, const BlackScholesMarket&, const BumpSizes&) { std::puts("bump_greeks: BumpSizes"); }
    // pde.hpp
    #ifdef FOLDED
    template <Exercise E>
    void require_valid(const Vanilla<E>&, const BlackScholesMarket&, const PdeSettings&) { std::puts("pde: PdeSettings"); }
    #else
    void require_valid(const EuropeanVanilla&, const BlackScholesMarket&, const PdeSettings&) { std::puts("pde: PdeSettings"); }
    void require_valid(const AmericanVanilla&, const BlackScholesMarket&, const PdeSettings&) { std::puts("pde: PdeSettings"); }
    #endif

    int main()
    {
        require_valid(EuropeanVanilla{}, BlackScholesMarket{}, {});
    }

  As the header is (two overloads), g++ 15.2.0 -std=c++20:

    fold.cpp:26:18: error: call of overloaded 'require_valid(EuropeanVanilla,
    BlackScholesMarket, <brace-enclosed initializer list>)' is ambiguous

  Folded (-DFOLDED), g++ 15.2.0 and clang++ 22.1.7 both compile it and print:

    bump_greeks: BumpSizes

  A non-template beats a template specialisation when their conversion sequences tie, and
  a braced {} converts to either settings struct by aggregate initialisation. So the fold
  turns a call that does not compile into one that validates bump sizes where a grid was
  meant. tests/test_contract.cpp, test_three_way.cpp and wasm/binding.cpp include both
  headers today. Decision in ARCHITECTURE.md section 8: all three pairs stay; no call site
  changed. The folded crank_nicolson and crank_nicolson_surface were not built against the
  suite.
