# `american_vanilla.json` — schema, and what a lattice value is worth

Reference values for **American**-exercise vanilla options under Black–Scholes–Merton,
generated by [`generate_american_vanilla.py`](generate_american_vanilla.py) from QuantLib
and read by `tests/test_american.cpp`. QuantLib is the oracle and never a dependency
(`CONSTITUTION.md` I4).

Schema id `touchstone/golden/american_vanilla@1`. A change to the meaning of any field, or
to the units below, is a new schema id — not an edit to this one.

## Why this file is not `bs_vanilla.json`

`bs_vanilla.json` carries a closed form evaluated to fifteen digits, and the C++ is compared
against it at a fixed tolerance of 10⁻¹⁰. **Nothing here is a closed form.** An American
vanilla's value solves a free-boundary problem, and every reference for it — lattice, grid,
integral equation — is itself a numerical method with its own error. A fixed tolerance
against such a file would be either a claim the oracle cannot support, or a tolerance so
loose that the easy rows pass on the hard rows' allowance.

So this file carries **a value and a measured uncertainty, per row**:

- `price`, `delta`, `gamma` — QuantLib's Leisen–Reimer lattice at 2001 steps;
- `spread`, `delta_spread`, `gamma_spread` — the largest disagreement between that and two
  other lattices on the same inputs: Cox–Ross–Rubinstein and Tian, each also at 2001 steps.

The three differ in how the up and down factors and the risk-neutral probability are chosen,
so they approach the answer along different paths and their spread is a measurement rather
than the same error computed three times. A test reads `price` and compares against it with
`spread` as the oracle's own uncertainty.

### What the spread is, and is not

Measured on the committed file: median 6.2 × 10⁻⁴, 99th percentile 1.5 × 10⁻², worst
2.0 × 10⁻². As a fraction of `max(|price|, strike)` — the scale a lattice's error lives on —
median 5.9 × 10⁻⁶, worst 1.8 × 10⁻⁴. The worst rows are all five-year options at 60%
volatility, where the trees are largest and the free boundary is longest.

The spread is **zero** wherever all three lattices return the intrinsic value exactly, which
happens on every row where immediate exercise is optimal at the spot. Zero is then honest
about the three trees and silent about the truth, so a test must carry a floor beside it.
The floor the C++ uses is 10⁻⁶ of the option's scale, and it is not arbitrary: on the 324
rows where the American value is provably equal to the European one (below), the lattice's
deviation from the closed form is at most 5.2 × 10⁻⁷ absolute, 4.8 × 10⁻⁹ scaled. That is
what these trees are actually worth where the truth is known.

## Fields

| Field | Type | Meaning |
|---|---|---|
| `type` | `"call"` \| `"put"` | Option type. |
| `spot` | float | `S`. |
| `strike` | float | `K`. |
| `vol` | float | `σ`, annualised, as a decimal. |
| `rate` | float | Continuously compounded `r`. May be negative. |
| `dividend_yield` | float | Continuous `q`. |
| `expiry_days` | int | Days from the evaluation date to expiry. |
| `expiry_years` | float | Exactly `expiry_days / 365`. |
| `price` | float | `V`, Leisen–Reimer at 2001 steps. |
| `delta` | float | `∂V/∂S`, per 1.00 of spot. |
| `gamma` | float | `∂²V/∂S²`, per 1.00 of spot squared. |
| `spread` | float | `max` over the two cross-check lattices of `|their price − price|`. |
| `delta_spread`, `gamma_spread` | float | The same, for the two Greeks. |

The conventions are `bs_vanilla.json`'s, unchanged: raw partial derivatives, no market
scaling, Actual/365 Fixed with whole-day expiries and the evaluation date fixed in source.
A row here and a row there with the same inputs describe the same contract.

## The grid

Full cartesian product: 3 × 3 × 4 × 2 × 2 × 3 × 2 = **864 rows**.

| Axis | Values |
|---|---|
| `spot` | 80, 100, 120 |
| `strike` | 90, 100, 110 |
| `vol` | 0.05, 0.15, 0.30, 0.60 |
| `rate` | −0.005, 0.05 |
| `dividend_yield` | 0.00, 0.04 |
| `expiry_days` | 91, 365, 1826 (≈ 3m, 1y, 5y) |
| `type` | call, put |

Smaller than the European grid, because a lattice at two thousand steps is five orders of
magnitude slower than a closed form and because what is measured here is narrower: the
early-exercise premium, which depends on moneyness, carry and time and not on absolute
scale. **495 of the 864 rows carry a material premium**; the largest is 22.81, on a
five-year 5%-volatility put struck 30 above the spot.

Three axis values are there for specific claims rather than for coverage.

- **`rate = −0.005`**, so that the file contains rows where an American *put* is worth
  exactly its European counterpart — there is no interest on the strike to be earned by
  exercising early — and rows where an American *call* is worth strictly more than its
  European counterpart. See below.
- **`dividend_yield = 0.00`**, so that the file contains rows where an American *call* is
  worth exactly its European counterpart.
- **`vol = 0.05`**, because low volatility is where the early-exercise premium is largest
  *relative to the option*, not smallest: a five-year at-the-money put at 5% volatility is
  worth twenty times its European value.

## Two exact identities, and their conditions

These are the only places an American value can be checked against a closed form, and they
are the strongest statements in the American suite — fifteen digits rather than a lattice's
four.

- **A call with `q = 0` and `r ≥ 0` is worth exactly its European counterpart.** Exercising
  early pays `K` now instead of `K e^{−rT}` later and gains nothing for it. 108 rows.
- **A put with `r ≤ 0` and `q ≥ 0` is worth exactly its European counterpart**, for the
  mirror-image reason. 216 rows.

**The conditions are load-bearing.** "Never exercise an American call early" is a theorem
about non-negative rates. At `r < 0` the strike is worth *more* later than now, so holding
the call costs money, and immediate exercise can be optimal. This file contains rows where
it is: a call at `S = 120`, `K = 90`, `σ = 0.05`, `r = −0.005`, `q = 0`, five years, whose
lattice value is exactly `30 = S − K` while the European value is 27.7576. 201 rows of the
grid have a call worth strictly more than its European counterpart at a negative rate.

The American put–call relation has a condition of the same kind:

```
S·e^(−qT) − K  ≤  C_A − P_A  ≤  S − K·e^(−rT)
```

Measured on the committed file, over the 216 pairs with `r ≥ 0` and `q ≥ 0`, both bounds
hold to 3.1 × 10⁻¹³ — arithmetic, not lattice error. Over the pairs with `r < 0` the lower
bound is breached by up to 2.5 × 10⁻², because the argument behind it assumes the call is
never exercised early and a negative rate is exactly when it is.

## Regenerating

```bash
uv sync
uv run golden/generate_american_vanilla.py     # rewrites american_vanilla.json (~2.5 min)
uv run golden/verify_american_vanilla.py       # independent cross-check, exit 0 on pass
```

The generator is deterministic in the same way `generate_bs_vanilla.py` is: the evaluation
date is fixed in source, the grid is fixed in source, no timestamp is written, and floats are
serialised at shortest round-trip precision. Same QuantLib version, same bytes.

`verify_american_vanilla.py` is the check that the file is worth trusting. It re-derives
every row with a Cox–Ross–Rubinstein tree written in numpy from the recursion — a different
scheme, a different step count (1200), and no QuantLib — and then asserts the two identities
against a closed form, the American-versus-European and American-versus-intrinsic
inequalities, the put–call bounds where they hold, and the file's own structure. It exists
because a generator that drove QuantLib wrongly — a European exercise object where an
American one belongs — would produce a perfectly self-consistent file, and nothing else in
the pipeline would notice.
