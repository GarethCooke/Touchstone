# Touchstone

A C++20 pricing and risk library for European vanilla options.

**In progress: nothing here works yet.** There is no C++ in this repository at the time of
writing. What exists is the governance, the Python oracle and the reference data the library
will be tested against — see [Status](#status).

Touchstone is one half of a pair. The other half is
[learn.garethcooke.com](https://learn.garethcooke.com), a tutorial for developers who work
alongside quants, whose checks are this library's tests and whose demos run on it. The
organising thesis of both: linear products are priced by discounting and no-arbitrage; only
nonlinear payoffs need stochastic calculus.

| [`docs/quant-learn-index-v1.md`](docs/quant-learn-index-v1.md) | The tutorial curriculum this library serves. |
| [`docs/evidence/`](docs/evidence/) | One pack per completed milestone: what was done, why, and the proof. |

Two rules shape everything in this repository, and both are worth knowing before you read
the code:

- **QuantLib is the oracle, never a dependency** (I4). Reference prices and Greeks are
  generated by QuantLib-Python, committed as versioned JSON, and read by the C++ tests.
  Touchstone does not link QuantLib, and will not.
- **Correctness is three-way agreement** (I20). Closed form, Monte Carlo and finite
  differences must agree within stated tolerances; analytic and bump Greeks likewise; Monte
  Carlo standard error is reported, never hidden.

## The Python side

Both `golden/` and `experiments/` are Python. The environment is a single `uv` project
rooted at the repository root; it exists only to run those scripts and is never linked into
the library.

```bash
uv sync                                  # Python 3.12, QuantLib, numpy — pinned by uv.lock
uv run golden/generate_bs_vanilla.py     # regenerate the golden file
uv run golden/verify_bs_vanilla.py       # check it against an independent implementation
```

`generate_bs_vanilla.py` is deterministic: same QuantLib version, same bytes. If the file it
writes differs from the committed one, either QuantLib changed or the grid did, and the diff
says which.

See [`golden/SCHEMA.md`](golden/SCHEMA.md) for the golden file's structure, units and
tolerances, and [`experiments/README.md`](experiments/README.md) for the script-plus-JSON
discipline every experiment follows.
